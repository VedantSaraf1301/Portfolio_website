# Vedant Saraf — Portfolio

Personal portfolio website built to showcase my projects, skills, and background as an Information Science student and Full Stack Developer.

**Live →** [https://VedantSarafPortfolio.app/](https://vedant-saraf-portfolio.vercel.app/)

---

## Built With

- **[Next.js 16](https://nextjs.org/)** — App Router, server-side API routes
- **[Framer Motion](https://www.framer.com/motion/)** — Page and scroll animations
- **[shadcn/ui](https://ui.shadcn.com/)** — UI component primitives
- **[Tailwind CSS v4](https://tailwindcss.com/)** — Styling
- **[Resend](https://resend.com/)** — Contact form email delivery
- **TypeScript** throughout

---

## Sections

| Section | Description |
|---|---|
| Hero | Typewriter role animation + social links |
